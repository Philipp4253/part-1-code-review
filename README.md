📋 О проекте:

В рамках задания был проведён полный аудит трёх рабочих процессов, выявлены критические уязвимости (SQL Injection, утечка секретов), логические ошибки и проблемы производительности. В папке workflows/fixed/ находятся исправленные версии файлов.

🛡️ Ключевые исправления:
1. Безопасность (Security):
SQL Injection: Во всех 3 воркфлоу запросы переведены на параметризованный стиль (VALUES ($1, $2)...).
Secrets Management: API-ключи (SendGrid) удалены из кода и вынесены в n8n Credentials (test_sendgrid).
Access Control: Настроена аутентификация для всех Webhook (Header Auth).
Path Traversal: В загрузчике файлов добавлена санитизация имён и проверка расширений (.jpg, .png и т.д.).

3. Логика и Производительность:
Logic Bug (Map Status): Исправлена ошибка дублирования обновления записей. Добавлена нода Edit Fields для корректной передачи ID между HTTP-запросами.
Cron Optimization: Частота опроса изменена с * * * * * на 0 */5 * * * *.
Limits: Добавлен LIMIT 5 в SQL-запросы для предотвращения перегрузки памяти.
